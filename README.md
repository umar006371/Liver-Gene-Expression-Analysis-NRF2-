🧬 NRF2 Liver Gene Expression Analysis

This project analyzes gene expression changes in liver disease using public datasets.

The focus is on the NRF2 pathway, which is important in:

oxidative stress
inflammation
liver disease progression
🎯 Aim of the study

To compare gene expression between:

Healthy liver samples (Control)
Diseased liver samples (e.g., NASH or liver injury)
🧪 What I did
Performed differential gene expression analysis
Compared Control vs Disease groups
Focused on NRF2-related genes
Generated visual plots to show results
📊 Results

The following plots were generated:

Volcano plot (shows significantly changed genes)
Bar charts (shows gene expression differences)
🔍 Key observation

Some genes showed increased expression in disease conditions, suggesting activation of stress and inflammation pathways.

NRF2-related changes may play a role in liver disease progression.
